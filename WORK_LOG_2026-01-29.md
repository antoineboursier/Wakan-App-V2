## 🐛 Problèmes rencontrés et solutions

### 1. Erreur "Failed to fetch" Supabase
**Cause** : Proxy PAC d'entreprise EDF (`http://pac-ad-edf.proxy.edf.fr`) bloquant les connexions HTTPS.

**Solutions testées** :
- ❌ Configuration Git proxy : échec (PAC non compatible)
- ❌ Hotspot mobile : proxy système toujours actif
- ✅ **Solution finale** : Utilisation du fichier **patch Git** pour transférer les modifications

### 2. Git push bloqué
**Cause** : Même proxy bloquant GitHub (port 443).

**Solution** : 
1. Création d'un fichier patch : `git format-patch origin/main`
2. Alternative : Connexion mobile + désactivation proxy (finalement réussie)

### 3. Typo dans `decans/page.tsx`
**Erreur** : `setEdited Decans` (espace dans le nom)
**Correction** : `setEditedDecans`

### 4. Double affichage de bloc saisons
**Cause** : Code dupliqué dans la migration
**Correction** : Suppression du bloc dupliqué

## 🔧 Points techniques importants

### Glow Effect sur les icônes
```tsx
className="w-12 h-12 rounded-full bg-[var(--background-800)]/50 backdrop-blur-md flex items-center justify-center border border-[var(--warning-500)]/30 shadow-[0_0_20px_rgba(255,215,0,0.2)] overflow-hidden relative"
```

### Migration Supabase safe
- Pas de renommage de tables (évite les problèmes de FK)
- Modifications des colonnes existantes uniquement
- Suppression des contraintes FK avant suppression de colonnes

### Structure admin consistante
- Une page = un module
- Formulaires directs (pas d'accordéon)
- Preview des images avec fallback
- Bouton "Enregistrer" uniquement si modifications détectées
